# バンドマシン

楽器練習用のバッキング生成・演奏 Web アプリです。コード進行を入力してジャンルとバリエーションを選ぶと、ドラム・ベース・ギター・キーボードのバッキングをブラウザで演奏します。サーバーや外部 API、サンプル音源は使いません（Tone.js の合成音）。仕様は [docs/spec.md](docs/spec.md) です。

## 起動方法

```sh
npm install
npm run dev          # 開発サーバー
npm test             # 単体テスト（Vitest）
npm run build        # 型チェック + 本番ビルド（dist/）
npx vite preview --port 4185 --strictPort --host 127.0.0.1   # ビルド結果の確認
```

`vite.config.ts` は `base: './'` です。ポート直下でも、サブパス配下でも配信できます。
iOS Safari では、最初の再生ボタンのタップで音声が有効になります。マナーモードのスイッチが入っていると音が出ない場合があります。

## 進行の書き方

- 小節は `|` で区切ります。1小節内のコードは空白区切りで、拍を等分します。
  - `| C | G | Am | F |` … 1小節に1コード
  - `| C G | Am F |` … 1小節に2コード（各2拍）
  - `| C G Am |` … 3コードは 2・1・1 拍（4/4 のとき）
- 1小節に入るコード数は拍数までです（4/4 なら4個、3/4 なら3個）。
- `%` または `-` は直前のコードの継続です。
  - `| C | % |` … 前の小節の繰り返し
  - `| C - G - |` … C を2拍、G を2拍
- `N.C.`（`NC` も可）は休みです。ドラムだけ鳴ります。
- 分数コード: `C/E`、`Am7/G`

対応するコード:

| 種類 | 例 |
|---|---|
| メジャー / マイナー | `C` `Cm` |
| セブンス系 | `C7` `Cmaj7`（`CM7`） `Cm7` `CmM7` |
| sus | `Csus2` `Csus4` `C7sus4` |
| 追加音・6th | `Cadd9` `C6` `Cm6` |
| ディミニッシュ・オーギュメント | `Cdim` `Cdim7` `Caug` `Cm7b5` |
| ナインス以降 | `C9` `Cm9` `Cmaj9` `C13` |
| テンション | `C7b9` `C7#9` `C7(b13)` `C7#5` `Cmaj7#11` |

入力に誤りがあると、何小節目のどの記号かをエラー表示します。エラーがある間は再生を始められません。再生中にエラーになったときは、直前の正しい内容のまま鳴り続けます。

## 機能

- **再生コントロール**: 再生/停止（同じボタン）、テンポ 40〜240（数値とスライダー。再生中も変更可）、ループ、カウントイン（1小節）、メトロノームクリック。スペースキーでも再生/停止できます。
- **キー・拍子**: 4/4 と 3/4。キーは「移調」（半音 -6〜+6）として、チャート全体を移調します。
- **ジャンルとバリエーション**: 下記の一覧。選ぶと推奨テンポに切り替わります。
- **コードチャート**: 小節グリッド。再生中の小節が緑でハイライトされます。小節をタップするとメニューが開きます。
  - **フィル**: なし / 自動（ジャンル既定） / タム回し / スネア連打 / シンプル（最後の拍） / ブレイク（全員のキメで止まる）。指定した小節にはマークが付きます。
  - **ループ範囲 (A-B)**: 「ここからループ開始」「ここでループ終了」で範囲を指定します。範囲外の小節は薄く表示されます。範囲を指定すると、ループなしでもその範囲だけを再生します。
  - フィルの次の小節の頭には、クラッシュシンバルが入ります。
  - **自動フィル**: 4小節ごと / 8小節ごとに自動でフィルを入れます（ループ範囲があれば範囲の先頭から数えます）。
- **ミキサー**: ドラム/ベース/ギター/キーボード/クリックそれぞれに、ミュート・ソロ・音量があります。ソロを1つ以上入れると、ソロのパートだけが鳴ります。
- **保存**: 進行・ジャンル・テンポ・フィル・ループ範囲・ミキサーなどは localStorage に自動保存し、次回起動時に復元します。

## 構成

```
src/
  music/      コード・進行・ボイシング・アレンジ・フィルの純粋関数（Vitest でテスト）
    chords.ts       コード記号パーサ
    progression.ts  進行テキスト → 小節・拍のチャート（エラー位置付き）
    voicing.ts      ギター/キーボード/ベースのボイシング（音域制限・最近接転回形）
    arrange.ts      チャート＋スタイル＋フィル指定 → 楽器別ノートイベント
    fills.ts        フィルの種類と自動フィルの位置
    types.ts        イベント型（音楽時間は小節/拍/16分）
  styles/     ジャンル×バリエーションのパターン定義（データ）
  audio/      Tone.js の楽器（Instrument インターフェイス）とスケジューラ、ミキサー解決
  ui/         React コンポーネントと設定の保存
```

### スタイルの追加

`src/styles/index.ts` の `GENRES` にバリエーションを書き足します。パターンはステップ列の文字列です。
ドラムは16分グリッド（または3連グリッド）で、`X` 強 / `x` 中 / `o` 弱 / `g` ゴースト / `.` 休みを並べます。
ベース・ギター・キーボードは、リズム＋奏法（ルート弾き、オクターブ、ウォーキング、パワーコード、ストローク、アルペジオなど）を文字で書きます。文字の意味は `src/styles/types.ts` の冒頭コメントにあります。
パターン長が1小節ぶんになっているかは、テストが全バリエーションを検査します。

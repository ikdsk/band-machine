# バンドマシン — 仕様 (MVP)

楽器練習用のバッキング演奏アプリ。コード進行を入力し、ジャンルとバリエーションを選ぶと、
ドラム・ベース・ギター(＋任意でキーボード)のバッキングを生成してブラウザで演奏する。

## 技術方針
- Vite + React 19 + TypeScript。ブラウザのみで完結（サーバー不要、外部API不要）。
- 音源: Tone.js による合成音（ドラムは MembraneSynth/NoiseSynth/MetalSynth、ベースは MonoSynth、
  ギターは PluckSynth＋Distortion などで近似）。外部サンプル音源は MVP では使わない（ライセンス/起動速度のため）。
  将来サンプル音源に差し替えられるよう、楽器は `Instrument` インターフェイスで抽象化する。
- 生成ロジック（コード解析・パターン生成）は純粋関数にして Vitest で単体テストする。音の再生層と分離する。
- UI は日本語。機能重視・シンプル（宣伝コピーなし）。スマホ(iPhone Safari)でも操作できるレスポンシブ。
- 状態は localStorage に保存（最後の曲を復元）。

## 機能要件
1. **コード進行入力**
   - テキスト入力: 小節区切り `|`、1小節内は空白区切りで拍を等分。例: `| C | G | Am | F |`, `| C G | Am F |`。
   - 対応コード: メジャー/マイナー/7/maj7/m7/sus2/sus4/add9/dim/aug/m7b5/6/m6/9、分数コード (`C/E`)、`N.C.`、
     同じコード継続 `%` または `-`。
   - パース結果はコードチャート（小節グリッド）として表示し、不正なコードはエラー表示。
   - キー・拍子(4/4、3/4、6/8 は将来でも可、MVPは4/4必須・3/4推奨)。
2. **ジャンル × バリエーション**（最低限）
   - ロック: 8ビート / 16ビート / ハードロック(パワーコード刻み) / シャッフル
   - アニソン: 疾走系(2ビート/表打ち速め) / 4つ打ちポップ / ハーフテンポサビ
   - バラード: シンプル8分 / 6/8風アルペジオ(3/4でも可) / ピアノ伴奏風(キーボード)
   - ポップス / ファンク / ブルース / ジャズ(4ビート・ウォーキングベース) / ボサノバ / レゲエ / メタル(2バス)
   - 各バリエーションはデータ(パターン定義)として追加しやすい構造にする。
3. **演奏コントロール**
   - 再生/停止、ループ（全体 or 指定小節範囲 A-B）、テンポ 40–240 BPM（再生中変更可）、
     カウントイン(1小節)のオンオフ、メトロノームクリックのオンオフ。
   - 楽器ごとの ミュート/ソロ/音量（ドラム・ベース・ギター・キーボード・クリック）。
     練習者が自分のパートを消せることが核心。
   - 再生位置の小節ハイライト。
4. **フィルイン**
   - 小節ごとにフィルを指定（チャートの小節をタップ→「フィル」トグル）。
   - フィル種類: 自動(ジャンル既定) / タム回し / スネア連打 / シンプル(最後の拍だけ) / ブレイク(全員キメで止まる)。
   - オプション「4小節/8小節ごとに自動でフィル」。
   - フィル後の次小節頭はクラッシュシンバル。
5. **セクション(任意・MVP後半)**: Aメロ/サビ等のセクションごとにバリエーション切り替え。

## 非機能
- 起動が速いこと。再生のタイミングは Tone.Transport でスケジューリング（setTimeout で発音しない）。
- iOS の音声アンロック（最初のタップで `Tone.start()`）。
- ベース・ギターのボイシングは音域を制限し、コード間は近い転回形を選ぶ（ボイスリーディング）。

## 受け入れの目安
- `| C | G | Am | F |` をロック8ビート 120BPM でループ再生でき、ドラム/ベース/ギターがそれぞれミュートできる。
- テンポを再生中に変えても破綻しない。4小節目にフィル指定すると4小節目でフィル、5小節目頭でクラッシュ。
- ジャンル切り替えでドラム・ベース・ギターのパターンが明確に変わる。
